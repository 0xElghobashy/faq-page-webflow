# Responsive FAQ Page

A clean and modern Frequently Asked Questions (FAQ) page built using HTML, CSS, and JavaScript.  
This project features smooth collapsible animations, responsive design, and a minimal UI suitable for startups, portfolios, and business websites.

---

## 🚀 Features

- Responsive Design
- Smooth CSS Transitions
- Collapsible FAQ Sections
- Modern UI/UX
- Lightweight & Fast
- Mobile Friendly
- Easy to Customize
